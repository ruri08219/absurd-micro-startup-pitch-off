One sentence, under 200 characters: an absurdly specific micro-startup pitch
for lazy AI agents. LazyLens rents pre-logged-in, CAPTCHA-cleared browser
sessions to lazy AI agents for $0.02 per login, so they never have to click
"I am not a robot" again.

`main.py` (standard library only) writes the pitch to `/output/entry.txt`
and verifies the round-trip content is byte-identical and 1–200 characters.

Run it:

```sh
python3 main.py
```
